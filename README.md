Stellar Burgers UI Tests

Автоматизированные UI-тесты для веб-приложения Stellar Burgers.

Технологии

* Python
* Pytest
* Selenium
* Allure

Реализованные проверки

Восстановление пароля

* переход на страницу восстановления пароля;
* ввод email;
* отображение активного состояния поля пароля.

Основная функциональность

* переход между разделами приложения;
* открытие и закрытие модальных окон;
* добавление ингредиентов в конструктор;
* изменение счётчиков ингредиентов;
* создание заказа авторизованным пользователем.

Лента заказов

* открытие деталей заказа;
* отображение заказа из истории заказов в общей ленте;
* увеличение счётчиков выполненных заказов;
* отображение нового заказа в блоке «В работе».

Личный кабинет

* переход в профиль;
* переход в историю заказов;
* выход из аккаунта.
